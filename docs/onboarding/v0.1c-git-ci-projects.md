# v0.1C Git 与 CI 项目接入

## 1. 数据边界

v0.1C 只读取：

- 本地 `git status --porcelain=v2 --branch`；
- 本地已有 remote-tracking refs；
- GitHub/GHES commit check-runs；
- GitHub/GHES combined commit status。

它不会执行 fetch、pull、push、commit、reset、checkout、merge、rebase，也不会重跑 Actions、下载完整 job logs 或写入 GitHub。

## 2. 本机环境变量

```bash
export PAC_PROJECTS_FILE="$HOME/.config/project-agent-controller/projects.yaml"
export PAC_SCM_PROVIDERS_FILE="$HOME/.config/project-agent-controller/scm-providers.yaml"
export PAC_LOCAL_REPOS_ROOT="$HOME/dev"
export PAC_GIT_EXECUTABLE="$(command -v git)"
export PAC_GITHUB_TOKEN="<fine-grained read-only token>"
```

公开仓库允许不配置 Token。私有仓库建议使用单仓库、只读 fine-grained token。Token 值不得写入 YAML、日志或 Git。

## 3. 配置

```bash
cp config/scm-providers.example.yaml \
  "$HOME/.config/project-agent-controller/scm-providers.yaml"
cp config/projects.git-ci.example.yaml \
  "$HOME/.config/project-agent-controller/projects.yaml"
```

`local://chan-shuo` 会解析为：

```text
$PAC_LOCAL_REPOS_ROOT/chan-shuo
```

控制器不会把解析后的绝对路径写入 SourceState 或 API。

## 4. Freshness 语义

Git Source 中的：

```text
ahead
behind
upstream
```

只来自本地已有 remote-tracking ref。控制器不会 fetch，因此它们必须和以下字段一起理解：

```json
{
  "remote_tracking_only": true,
  "remote_freshness": "unknown"
}
```

CI Source 使用本地当前 HEAD SHA 查询 GitHub。它能反映该 SHA 的云端检查结果，但不能证明本地 tracking ref 已同步到远端最新分支头。

## 5. 两周期预检

```bash
PAC_VERIFY_MODE=offline ./scripts/verify-v0.1c.sh
```

真实 Git 预检包括：

1. 初始化临时仓库；
2. 首次观察生成 `git.available`；
3. 第二周期稳定无事件；
4. 修改文件后生成 `git.dirty.entered`；
5. Emergency Stop 时 Provider 不被调用。

## 6. GitHub 公共仓库预检

联网环境：

```bash
PAC_PREFLIGHT_GITHUB=1 \
PAC_V01C_PUBLIC_REPOSITORY=lpearf-pixel/project-agent-controller \
PAC_V01C_PUBLIC_SHA=<40位提交SHA> \
./scripts/preflight-v0.1c.sh
```

私有仓库预检另需：

```bash
export PAC_GITHUB_TOKEN="..."
export PAC_V01C_PRIVATE_REPOSITORY="owner/private-repo"
export PAC_V01C_PRIVATE_SHA="<40位提交SHA>"
```

预检只发送 GET；任何 Token 都不得出现在输出。

## 7. 查询

```bash
curl 'http://127.0.0.1:9090/v1/projects/chan-shuo/sources?kind=git'
curl 'http://127.0.0.1:9090/v1/projects/chan-shuo/sources?kind=github_ci'
uv run pac sources chan-shuo --kind git
uv run pac sources chan-shuo --kind github_ci
```

## 8. 停止

```bash
uv run pac controller emergency-stop \
  --actor local-admin \
  --reason 'pause all observers'
```

Emergency Stop 在 Git subprocess 和 GitHub HTTP 请求之前生效。
