# v0.1B 首批项目接入与预检

v0.1B 只观察，不执行下面的命令。以下命令由管理员在本机手工运行，用于确认配置是否唯一和安全。

## 1. 准备本机目录

```bash
mkdir -p "$HOME/project-agent-sources/person-relation-lab"
mkdir -p "$HOME/project-agent-sources/chan-shuo"
export PAC_LOCAL_SOURCES_ROOT="$HOME/project-agent-sources"
export PAC_PROJECTS_FILE="$HOME/.config/project-agent-controller/projects.yaml"
export PAC_DATA_DIR="$HOME/.local/share/project-agent-controller"
export PAC_KNOWLEDGE_DIR="$HOME/dev/project-agent-knowledge-private"
```

PID 文件由被观察服务的启动脚本写入；Controller 不负责启动服务：

```bash
printf '%s\n' '<PID>' > "$PAC_LOCAL_SOURCES_ROOT/person-relation-lab/importer.pid"
chmod 600 "$PAC_LOCAL_SOURCES_ROOT/person-relation-lab/importer.pid"
```

PID 文件只允许一个十进制正整数。不要使用模糊进程名匹配。

## 2. Docker Endpoint

Docker Socket 是高权限本地接口。优先使用 rootless Docker Socket 或只暴露 GET 白名单的 Socket Proxy。直接使用系统 Docker Socket 时，Controller 进程必须运行在专用低权限账户下。

示例：

```bash
export PAC_DOCKER_SOCKET="$HOME/.docker/run/docker.sock"
```

系统 Docker 常见位置是 `/var/run/docker.sock`，但不要把该绝对路径写进项目 YAML。

## 3. 验证 Compose selector 唯一

```bash
docker ps --filter 'label=com.docker.compose.project=person-relation-lab' \
  --filter 'label=com.docker.compose.service=db' \
  --format '{{.ID}} {{.Names}}'
```

输出必须恰好一行。零行表示容器尚未运行；多行会触发 `docker.selector.ambiguous`，Controller 不会合并多个容器的日志。

对社区小程序分别验证 `api` 和 `admin` service。

## 4. 验证 PID 身份

```bash
pid="$(cat "$PAC_LOCAL_SOURCES_ROOT/person-relation-lab/importer.pid")"
ps -p "$pid" -o pid=,lstart=,comm=
```

Controller 使用 `PID + create_time` 识别进程重启或 PID 复用，不读取完整 cmdline、环境变量或工作目录。

## 5. 启动与查询

```bash
uv run pac serve
curl http://127.0.0.1:9090/v1/projects/person-relation-lab/sources
uv run pac sources person-relation-lab
```

返回仅包含当前安全快照。不得出现 Docker Env、Mounts、完整 labels、Docker Socket、PID 文件路径或完整 cmdline。

## 6. 两周期稳定性检查

启动后等待两个轮询周期：

```bash
curl 'http://127.0.0.1:9090/v1/projects/person-relation-lab/events?limit=100'
```

没有状态变化时，不应每轮产生 lifecycle 或 resource 事件。只有首次 available、阈值跨越、新日志和 heartbeat 会写入事件库。

## 7. Emergency Stop 检查

```bash
uv run pac controller emergency-stop local-admin 'v0.1b preflight'
```

确认 SourceState 的 `observed_at` 和事件数量不再变化。解除后只进入 `RECOVERING`，不会自动恢复：

```bash
uv run pac controller clear-emergency-stop local-admin 'preflight complete'
uv run pac controller complete-recovery local-admin 'recovery checks passed'
```

## 8. 首批验收记录

每个真实项目接入时，在私有知识仓库保存：

- selector 验证时间和结果；
- PID 文件生成责任方；
- 两周期事件量；
- Emergency Stop 结果；
- 已发现的 Known Problem；
- 适用的 Lesson。

不要保存原始日志、Token、私钥、完整环境变量或用户数据。
